# Introduction
This is the repo to contain the function and files to provide testing on search-LEI cloud function(https://github.com/xyz-Group/search-lei)

# Flies and Folders

The principal components of the function are implemented in the files below

- *test_app.py* - a reference Python script to demonstrate the usage of the function (request and response flow)
- *requirements.txt* - the PIP requirements file to list dependency packages for the testing source code unit

The additioal files are as follows

- *excel_utility.py* - Python script to provide test cases data from excel file(from excel to json))
- *data/test_cases.json* -  file with test cases to check the operability of serach Lei cloud function
