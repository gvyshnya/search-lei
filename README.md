# Introduction
This is the repo to contain the Google cloud function to provide the fuzzy search on the LEI dataset.

# Flies and Folders

The principal components of the cloud function are implemented in the files below

- *main.py* - the main source code unit of the function
- *requirements.txt* - the PIP requirements file to list dependency packages for the main source code unit

The additioal ffiles are as follows

- *testing.json* contains the example of the cloud function input parameters (it can be used in the interactive cloud function testing)
- *test_cloud_function.py* - a reference Python script to demonstrate the usage of the cloud function (request and response flow)
